# 🦆 Microduck Feetech HD1910 Replica

A working robot-duck replica based on [Pollen Robotics Microduck](https://github.com/pollen-robotics/microduck), with a **Radxa ZERO 3W system image, Chinese-language Robot Console, reinforcement-learning Training Studio, DIY HAT / IMU boards and complete 3D printing files**.
